# FUR:RAID 2026 Main Theme

FUR:RAID 2026과 SNOWRICE STUDIO가 함께 제작한 메인 테마곡의 스트리밍 안내 페이지입니다. 음원 공개 전에는 `곧 공개됩니다.` 화면을 표시합니다.

한국어·영어·일본어를 지원하며, 공개 후 Spotify, Apple Music, YouTube Music, LINE MUSIC, Amazon Music, iTunes 링크와 선택적인 Spotify 임베드 플레이어를 표시할 수 있습니다.

공개할 때는 `site-config.js`에서 `comingSoon`을 `false`로 바꾸고 각 서비스의 `url`을 입력하세요. Spotify 플레이어를 사용하려면 `spotifyPlayerUrl`도 설정하면 됩니다.

HTML·CSS·JavaScript로 만든 정적 사이트이며 시작 파일은 `index.html`입니다.
